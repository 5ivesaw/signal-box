Local engine & downloads

The first processing action fetches about 69 MB of runtime code. Media stays on your device. Start with a short 480-pixel preview.

Process, model, authored

Process uses the named operation. Model approximates it. Authored effects need material you supply; 42 catalog entries require assets.

Desktop-only dependencies

GSM, Codec2 and Rubber Band require native FFmpeg. Browser memory limits also make the desktop app preferable for long renders.

Adaptive selection

Analyzes the entire video and audio with explained measurements. It uses multivariate heuristics, not a trained neural network.
